# Contributing

Thanks for helping improve this repo!

## Adding a question

1. Pick the matching topic file (or open an issue if no topic fits).
2. Use this format:

   ```markdown
   ## Q<number>. Your question?

   **Answer:** A clear, concise answer in your own words.

   ```java
   // optional example
   ```
   ```
3. Keep answers accurate, short, and original. Do not copy text from other websites.
4. Open a pull request with a short description of what you changed.

## Fixing mistakes

If you find an error, open an issue or send a PR with the correction and a short explanation.
