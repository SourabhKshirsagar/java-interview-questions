# Core Java Interview Questions and Answers (2+ Years Experience)

A practical collection of **core Java** interview questions with answers, for developers with roughly 2 to 3 years of experience. No Spring or other frameworks, just the Java fundamentals interviewers expect you to know.

## How to use this repo

1. Read one topic file at a time.
2. Cover the answer and try to explain it out loud first.
3. Run the examples in [`coding-questions/`](coding-questions/) to see the behavior yourself.
